🗑 Eliminar Carga

Acción permanente
⚠️  Se borrará la fecha registrada de esta carga. Esta acción no se puede deshacer.

🗑 Eliminar Proyecto

Acción permanente
⚠️  Se eliminará el proyecto completo de la base de datos, junto con todos sus hitos y cargas registradas. Esta acción NO se puede deshacer.

⛔ Cierre Forzado

Se registra fecha/hora exacta · Acción permanente
⚠️  El proyecto quedará como Cierre Forzado. No puede revertirse.

↩️ Devuelto a ITO

Se registra fecha/hora exacta · el proyecto sigue activo
↩️  El proyecto queda marcado como pendiente de corrección por el ITO hasta que se registre la liberación.

📊 Exportar datos

Los cambios se guardan automáticamente en la base de datos compartida (Supabase) — cualquiera con este link ve lo mismo, en cualquier equipo. El export sigue sirviendo como respaldo manual.

💡 El CSV abre directo en Excel con todas las columnas, fechas y estados. El JSON permite restaurar datos en otro equipo.
