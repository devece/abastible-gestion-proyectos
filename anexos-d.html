📎 Anexos D — Suministro Provisorio

Formatos disponibles para el supervisor: usar uno para completar o enviar una copia en blanco.
💡 ¿Qué formato elegir? Word — se llena en Word, se agrega la firma como imagen y se imprime a PDF. HTML — se llena online en el navegador, se agrega la firma como imagen y se imprime a PDF. PDF — se imprime directo, se llena a mano, se firma, se escanea y se envía.

Anexo 1 — Suministro Provisorio

Autorización de suministro provisorio de GLP mientras se regulariza la instalación definitiva.
Word (.dotx)

HTML (online)
